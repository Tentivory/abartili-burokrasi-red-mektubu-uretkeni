# Abartılı Bürokrasi Red Mektubu Üretkeni

## Bu Nedir?

Bu, insanlık tarihinin en önemli yazılımıdır. Devlet dairelerinde yaşanan o efsanevi "dosyanız eksik" anılarını dijital çağa taşıyan, asla onay vermeyen, her zaman red yazan Python scriptidir.

**Neden var?** Çünkü hayat zaten bürokrasi, kod da öyle olsun.

## Nasıl Çalışır?

1. Scripti çalıştır.
2. Adını gir.
3. Red mektubu al.
4. Ağla.
5. Tekrar dene (sonuç aynı).

```bash
python burokrasi_red_uretkeni.py
```

## Özellikler

- %100 red garantisi
- Rastgele absürt sebepler
- Resmi görünümlü format
- Copilot'a sorulsa "bu kod çalışıyor mu?" diye, "evet ama seni reddeder" derdi
